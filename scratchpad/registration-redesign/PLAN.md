## 2. 원칙

1. **등록 화면 = 공개 화면의 거울** — 같은 순서·같은 이름·같은 부품. 미리보기는 실제 상세 부품으로 그린다(따로 흉내 내면 오늘의 갤러리 폼처럼 낡는다). ⚠️ 구현 뒤 로컬 확인에서 사용자 결정(2026-11-15): **미리보기는 상세 하나** — 갤러리 홈페이지 · 공고 상세 · 전시 상세만, 찾기(목록) 카드는 안 보여 준다.
2. **왼쪽 입력 · 오른쪽 미리보기**(PC) / **[미리보기] 전체 화면**(휴대폰) — 홈페이지 편집(규칙 60)과 같은 틀.
3. **하단 고정 줄** — [임시저장] · [등록 요청] + '남은 필수 N · 칸 이름'(누르면 그 칸으로). 지원서·홈페이지 편집과 같은 자리(휴대폰은 탭바 위).
4. **약관은 [등록 요청] 확인 창 안으로** — 무엇이 올라가는지 요약 + 동의 체크 + [등록 요청]. 폼 본문에서 긴 약관 상자가 빠진다.
5. 설명 글은 최소(사용자 원칙). 남기는 건 결과를 바꾸는 정보뿐 — '11.20(금)부터 목록에 보여요', '공개 안 함'.

## 3. 공모 등록 (갤러리 공모 · 아트링크 주최 공모 공용 — 규칙 77 처럼 한 틀)

순서 = 공고 상세 순서:
1. **공고** — 포스터(작게, 2:3 · 자르지 않는다) 옆에 공모 제목 · 갤러리(승인된 갤러리가 하나면 고르는 칸 없이 이름만)
   - 아트링크 주최: 이 자리에 '운영 갤러리(선택, 여러 곳)'
2. **일정** — 맨 위에 진행 범위(전시까지 / 공모만 — 아래 칸이 갈리므로 여기). 그 아래 SchedulePicker 그대로(달력 규칙 77 유지)
3. **모집 내용** — 유형(글자 단추, 고르면 밑줄) · 모집 인원(CapacityPicker) · 지역(**고른 갤러리의 지역으로 미리 채움**)
4. **첨부파일**(선택)
5. **공모 소개**(서식 있는 글, 그대로)
6. **추가 질문**(선택, 접어 둠)

미리보기(오른쪽 · 휴대폰은 [미리보기] → [모집공고 목록 | 공고 상세] 두 탭):
- 모집공고 목록 카드(PC 격자 카드 / 휴대폰 줄) + "11.20(금)부터 보여요"(시작일이 미래면)
- 공고 상세 첫 화면 — 마감 표시 · 제목 · 주최 · **일정 띠** · 모집 내용 · 첨부
- 입력하는 대로 바뀐다. 상세 화면 크게 보기는 같은 부품을 시트로.

없애는 것: 맨 위 '공모는 이렇게 진행돼요' 띠(진행 범위 카드가 같은 말을 한다) · 폼 끝 약관 상자 · 토스트로 빈 칸 나열(하단 줄이 대신).

## 4. 갤러리 등록

1. **기본** — 대표 사진(4:3 · contain, 홈페이지·카드와 같은 모양) · 갤러리 이름 · 한 줄 소개(글자 수 표시 — 카드 두 줄·홈페이지 첫 화면에 그대로)
2. **방문 정보** — 주소(**주소 검색** → 시·도·구가 정확해져 카드에 '서울 종로구' · 지역 자동 선택, 바꿀 수 있음 · 직접 입력도 된다) + 상세 주소 · **관람 시간(선택)** · 전화 · 이메일(선택) · 인스타그램(선택)
3. **홈페이지 주소(선택)** — `artlink.cc/@` + 중복 확인(작가와 같은 이름공간 — `handleTaken`, 규칙 49)
4. **확인용 · 공개 안 함** — 대표자명

미리보기: 갤러리 찾기 카드 + 갤러리 홈페이지 첫 화면(이름 · 한 줄 소개 · 버튼 줄 · 방문 정보 · 사진).
승인 뒤에 채우는 것(사진 여러 장 · 소개 본문 · 비회원 문의)은 그대로 홈페이지에서.

## 6. 서버

- `POST /galleries` — `openHours`(80자, PATCH 와 같은 검사) · `handle`(형식 + `handleTaken` — 심사 중 갤러리도 그 주소를 잡는다. 거절·삭제되면 풀린다)을 받는다.
- 지역 자동 판정은 화면(`lib/listings.ts` 옆에 `regionFromAddress` — 서울·부산… 그대로, 경기는 시·군으로 북부/남부(고양·파주·의정부·양주·동두천·포천·연천·가평·남양주·구리 = 북부)). 서버 검사(`isRegion`)는 그대로.

## 7. 하지 않는 것

- 전시 등록(`/shows/new`) — 요청 밖. 같은 틀로 나중에.
- 등록 뒤 화면(내 공모·내 갤러리 카드) 개편 · 포스터 여러 장 한 번에 올리기(승인 뒤 포스터 관리 그대로).
- 약관 문구·판본(버전 기록 없는 체크박스 약관 그대로 — 자리만 옮긴다).

## 8. 정할 것

1. **약관을 [등록 요청] 확인 창 안으로** 옮길까 — 권장 예(폼이 짧아지고, 등록 직전에 무엇이 올라가는지 함께 본다).
2. **주소 검색**(다음 우편번호 서비스 — 무료, 키 없음, 외부 스크립트 하나)을 붙일까 — 권장 예(직접 입력도 남긴다).
3. 갤러리 등록 때 **관람 시간·@주소**도 받을까 — 권장 예(둘 다 선택 칸).
4. 일정 이름을 **'접수 시작일·접수 마감일'**로 통일할까(지금 폼 '공모 시작일/마감일' ↔ 상세 '접수 시작/마감') — 권장 '접수'(지원하는 작가에게 익숙한 말).
5. 맨 위 **'공모는 이렇게 진행돼요' 띠**를 없앨까 — 권장 예(진행 범위 카드가 같은 말).

## 11. 이미 등록된 갤러리의 주소 (결정 2 의 후속)

실서버 복제본(2026-11-15 덤프)의 승인된 실제 갤러리 10곳을 `addressCheck` 로 재면 **2곳**이 걸린다(가상 '아트링크 갤러리' 제외):
- **주소와 지역이 다르다** — '스포피아 갤러리'(주소 인천 연수구 · 지역 서울) → 지역 거르기 '서울'에 나오고 '인천'에선 빠진다.
- **주소를 못 읽는다** — 'Gallery H.art bridge'(주소 'H 아트브릿지') → 카드가 동네 대신 '서울'만.
- 나머지 8곳은 정상 — 카드에 '서울 종로구'·'인천 연수구'·'경남 양산시'·'부산 해운대구' 처럼 나온다.

한 것(로컬):
1. 방문자 화면은 깨지지 않는다 — 못 읽으면 지역 이름으로 대신한다(`addressArea`).
2. **주인에게만** 갤러리 홈페이지 방문 정보의 주소 아래 한 줄 — '주소와 지역(서울)이 달라요 · 주소 다시 넣기' / '주소 검색으로 다시 넣기' → 누르면 [정보 수정] 칸이 열리고,
   주소 칸이 [주소 검색] 칸(`AddressField`)이 됐다. 검색으로 고르면 지역이 따라온다.

더 할 수 있는 것(정하지 않음 — 사용자에게 묻는다):
- 그 두 갤러리 주인에게 알림 한 통(바깥으로 나가는 일이라 확인 필요).
- 관리자가 직접 고칠 수 있게(지금 주소·지역 수정은 주인만 — 정책 변경).
