## 1. 사용자 결정 (2026-11-13)

> "칼럼 쓰는 게 따로 있는 게 아니라 **커뮤니티 글쓰기 전체**를 이 수준의 도구로. 칼럼은 **탭으로 구분**. 짧은 글도 같은 도구로. 커뮤니티 UI/UX 도 신경 써라."

| 정한 것 | 결과 |
|---|---|
| 칼럼 = 따로 만든 종류? | **아니다.** `Post` 를 넓혔다(`doc`·`docVersion`·`coverUrl`·`excerpt`). 주소는 `/community/:id` 그대로 |
| 종류 | **탭(`PostCategory`)이 곧 종류** — 관리자가 만든다(작업일지·꿀팁·전시 후기·전시 준비…) |
| 누가 쓰나 | **탭마다** `writePolicy: all \| writers \| admin`. 필진은 `CommunityWriter`(역할 무관, 관리자가 넣고 뺀다) |
| 목록 모양 | 탭마다 `layout: list \| card`. 전체 탭 맨 위 '필진의 새 글'(필진 탭의 실명 글 3장) |
| 발행 창 | **없다.** 탭·익명은 제목 위에서 고르고 [등록]. 표지는 첫 사진(사진 도구 [표지로]로 바꾼다), 요약은 자동 |
| 익명 | 그대로. 탭마다 막을 수 있다(`allowAnonymous` — 막힌 탭에 익명이면 400, 말없이 실명으로 바꾸지 않는다) |
| 이웃 알림 | **필진 탭의 실명 글**을 처음 올릴 때만(`POST_NEW`) — 익명이 드러나지 않게, 잡담마다 알림이 가지 않게 |
| 옛 글 | DB 를 고치지 않는다. `doc` 없는 글은 `body`+`images` 로 그린다. 고치면 새 형식 |

## 2. 만든 것

### 서버
- **마이그레이션 둘**: `20261113120000_community_editor`(글 문서 칸 · 탭 정책 넷 · `PostDraft` · `PostAsset` · `CommunityWriter`, `writeAdminOnly=true` 는 `writePolicy='admin'` 으로 옮긴다) · `20261113130000_post_excerpt`(`Post.excerpt` 목록 요약).
- `lib/postDoc.ts` — 문서 허용 목록 검증 `sanitizePostDoc(raw, 'draft'|'publish')`(등록은 엄격 400, 작업본은 느슨) · 사진은 `ownFileUrl` · 링크는 http·https·mailto·같은 사이트 · 유튜브 id 11자 · `postDocText`(멘션·검색·옛 화면용 body) · `postDocLede`(목록 요약 — 맨 바깥 문단만) · `applyAssetInfo`(사진 치수·큰 썸네일은 서버 기록이 이긴다) · `legacyToPostDoc`.
- `lib/communityAccess.ts` — 탭 쓰기 판정 하나(`writeBlockReason`)를 등록·탭 목록 `canWrite`·작업본이 같이 쓴다 · 익명 판정 `resolveAnonymous`.
- `routes/community.ts` — 작업본 `/drafts`(rev 맞을 때만 저장 → 아니면 409 · 새 글 작업본 30개 `withKeyLock` · 고치기 작업본은 글당 하나 P2002 경합 처리) · 등록/수정(문서 또는 옛 형식 · 문서 글을 옛 형식으로 고치면 409) · 필진 `/writers`(넣으면 그 사람에게 알림 한 번) · 목록 `policy=writers`·`take` · 인기 `days` · 상세(작성자 홈페이지·한 줄 소개 · 이 탭의 다른 글 3) · 목록은 `rowSelect`(문서 JSON 을 안 읽는다).
- 글 사진 `POST /api/upload/post-image` → `{url,width,height}` · t240·t800·**t1280** 을 응답 전에 만든다 · `PostAsset` 기록. 파일 지우기는 썸네일 세 폴더 모두.
- 사진 파일 정리 `lib/postAssets.ts` — 글쓰기로 올린 것만, 어느 글·작업본도 안 쓸 때만(남의 파일·다른 글 사진은 안 지운다) · 버려진 사진은 3일 뒤 한 시간에 한 번 정리.
- `index.ts` — 커뮤니티 JSON 1MB · 자동 저장 PUT 은 전역 한도(300/15분)에서 빼고 따로 600/15분 · 공유 미리보기(`seoMeta` kind `post` — 리드 요약·표지) · 사이트맵에 필진 탭 실명 글.

### 화면
- **글쓰기** `/community/write` · `/community/:id/edit` — **Layout 밖**(상단바·하단 탭바·팝업 없음). 편집기(`components/post-editor/`, TipTap)는 이 화면에서만 lazy 로 받는다.
  - 글: 제목 · 소제목 2단계 · 굵게·기울임·밑줄·취소선·형광 · 링크 · 목록 · 인용(선·크게) · 팁 상자(팁·메모) · 가운데 · 구분선 · 되돌리기.
  - 사진: 커서 자리에 넣기 · 여러 장이면 [한 장씩 / 모아 놓기] · 크기(본문 폭·넓게·화면 폭) · 모음 배치(줄·격자·넘겨 보기) · 자르기·돌리기(`CropDialog`, 따로 받는 청크) · 설명·대체 글 · 표지로 · 바꾸기 · 위/아래 · 끌어 옮기기 · 동시 2장 업로드·자동 재시도·HEIC/크기 검사 · 붙여 넣은 글의 사진은 빼고 알린다.
  - 영상: 유튜브 주소 → 읽는 화면은 썸네일을 눌러야 iframe(facade).
  - 휴대폰: 도구 막대를 **자판 바로 위**(`visualViewport`), 사진을 고르면 막대가 사진 도구로 바뀐다.
  - 저장 안전망: 2초 쉬면(최대 10초) 서버 작업본에 자동 저장 · 한 번에 하나 · 실패하면 5/10/30/60초 재시도 · 이 기기에도 보관(서버보다 새로우면 [이어서 쓰기]) · 다른 탭·기기에서 저장했으면 "다른 곳에서 고친 내용이 있어요"(그 내용 불러오기 / 지금 내용으로 덮어쓰기) · 로그인이 풀리면 로그아웃시키지 않고 "다시 로그인해 주세요"(`skipAuthLogout`) · 새 버전 배포 때 자동 새로고침을 미룬다(`swUpdate holdReload`) · 새 글 화면에서 '쓰던 글 N개 → 이어 쓰기'.
- **읽는 화면** `/community/:id` — `PostBody`(편집기 없이 React 요소로, `dangerouslySetInnerHTML` 없음) · 경로(커뮤니티 / 탭) · 읽기 진행 막대(본문 기준) · 크게 보기(ImageLightbox) · 좋아요·공유 · 작성자 카드(이웃 추가·홈페이지) · 댓글(@멘션) · 이 탭의 다른 글(휴대폰은 한 줄씩) · 처음 올린 직후 "글을 올렸어요 [공유]".
- **목록** `/community` — `Community` 머리 · 글자 탭(`role=tab`) · 탭 소개 · 필진의 새 글 · 최신/인기 · 내 글/내 댓글 · 목록형/카드형 · 이번 주 인기글 · 휴대폰 떠 있는 [글쓰기].
- **탭 관리**(관리자) — 탭마다 누가 쓰나·목록 모양·익명·한 줄 소개 · [필진] 회원 찾기·넣기·빼기.
