# ArtLook 화면 하니스 (2026-10-04, CLAUDE.md 규칙 65)

마이페이지 [ArtLook] 탭(iframe `public/artlook/index.html` + `ui.js`)이 **어느 엔진·어느 화면에서도 첫 화면에 미리보기가 통째로 보이고,
[이미지 저장]이 하단 탭바 위에서 눌리고, 열 때 한 번만 그리고, 고른 것만 받는지** 잰다.
E2E(`e2e/tests/69-artlook-ux.spec.ts`)는 크롬 한 엔진·두 화면으로 **로직**(눌러서 무슨 일이 나는가)을 보고, 여기는 **기하·무게·사파리 엔진**을 본다.

```bash
bash scratchpad/hero/setup-webkit.sh        # 최초 1회 — WebKit 을 sudo 없이 띄울 준비(~/.cache/wk-deps)
# 데모 DB(artlink)로 띄운 서버가 있어야 한다 — 기본 5183/4001:
#   cd backend && PORT=4001 DATABASE_URL=<로컬 artlink> npx tsx watch src/index.ts
#   cd frontend && VITE_API_URL=http://localhost:4001 npx vite --port 5183 --strictPort
cd e2e && PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 node ../scratchpad/artlook-ux/walk.js
#   ENGINE=chromium|webkit · SCREEN=iphone13,se · SHOTS=1(out/ 에 탭마다 스크린샷) · VERBOSE=1(통과한 줄도)
```

- 계정은 데모 DB 의 `maker.walk@demo.artlink.local`(작품 12점, 진짜 업로드 — t800 썸네일이 있다). **아무것도 쓰지 않는다**
  (저장은 내려받기만, [ArtStory에 올리기]는 누르지 않는다).
- 2 엔진 × 8 화면(PC 1280·1440·1024, 아이패드, 픽셀 7, 아이폰 13, 갤럭시 360, 아이폰 SE) = 크롬 138 + 사파리 120 확인.

| 번호 | 무엇을 재는가 | 고치기 전(2026-10-04 실측) | 지금 |
|---|---|---|---|
| ① | 첫 화면 — iframe 이 하단 탭바 위에서 끝나고, 미리보기가 통째로 보이고, [이미지 저장] 자리를 누르면 저장 단추 | iframe y436~457 시작(프로필 카드 밑). 미리보기 첫 화면 보임: 아이폰 13 **0px** · PC 1280 278/444px. 저장: PC 화면 밖 | iframe y116(휴대폰)·y150(PC). 미리보기 아이폰 13 234px · 픽셀 7 392px · PC 1280 577px 통째로. 저장 늘 보인다 |

| ④ | 휴대폰에서 끌면 작품이 움직이고 바깥이 안 밀린다(크롬, CDP 터치) | 미리보기 칸이 63~73px 같이 밀림 | 0px |

⚠️ '전체' 열의 11.6MB 는 **개발 서버**(번들 안 된 모듈)라 크다 — 실서버는 번들이라 훨씬 작다. 비교는 'ArtLook' 열로.
⚠️ 헤드리스는 GPU 가 없어 합성이 느리다(첫 그림 1.8~4.6초). 실기기 시간은 따로 봐야 한다.

## 이 하니스가 잡은 것
- 좁은 칸(휴대폰·1024px 노트북)의 칩 칸이 고정 높이(140px)인데 액자 설명 줄이 2~5px, 매트 설명이 2px 아래로 잘렸다 → 144px + 안쪽 여백 조정 + 액자 설명은 한 줄.
- (넓은 칸은 패널이 위아래로 스크롤되므로 넘쳐도 잘림이 아니다 — 판정에서 뺀다)

## 화질은 따로
합성 결과(액자·그림자·조명)는 `scratchpad/vt/` 가 본다. 이번 개편은 엔진을 건드리지 않았다 — 기준 렌더 10장이 **픽셀 단위로 같다**
(전부 미리 받는 하니스 경로와, 고른 것만 받는 실제 경로 둘 다. 워터마크 빨강 #dc3545 → #c4302b 만 그 글자 자리에서 바뀐다).
vt 하니스는 `?preload=all` 로 연다(2026-10-04 부터) — 고른 것만 받게 바뀌어서, 상태를 코드로 갈아 끼우는 하니스는 전부 미리 받아야 한다.
