# 홈페이지 편집 화면 기하 하니스 (2026-10-02)

작가 홈페이지 편집 화면(`frontend/src/components/homepage-edit/`)이 **어느 엔진·어느 화면에서도 첫 화면에 할 일이 들어와 있고,
버튼이 눌리는지** 잰다. E2E(`e2e/tests/62-homepage-editor.spec.ts`)는 크롬 한 엔진·한 화면으로 **로직**을 보고,
여기는 **기하**(가림·넘침·sticky)와 **사파리 엔진**을 본다.

```bash
bash scratchpad/hero/setup-webkit.sh        # 최초 1회 — WebKit 을 sudo 없이 띄울 준비(~/.cache/wk-deps)
# 프론트(5173)와 백엔드(4000)가 **로컬 데모 DB(artlink)** 로 떠 있어야 한다. 실서버 복제본(artlink_prod)이면 스스로 멈춘다.
cd e2e && PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 node ../scratchpad/homepage-edit/walk.js
#   ENGINE=webkit|chromium  한쪽만 · SCREEN="iPhone SE"  한 화면만 · SHOTS=1  스크린샷(out/)
#   BASE=http://localhost:5183 API=http://localhost:4001/api  다른 포트로 띄웠을 때
#   DEMO_DATABASE_URL=…localhost:5432/artlink  backend/.env 가 복제본(artlink_prod)을 가리킬 때 — 계정을 심을 데모 DB
```

- 2 엔진 × 7 화면(PC 1280·1440, 아이패드 미니, 아이폰 13·SE, 갤럭시 360, 픽셀 7) × 18항목 = **252 확인**. 하나라도 어기면 종료 코드 1.
- 계정은 `backend/scripts/seed-nudge-demo.ts` 의 둘(작품 0점 / 일부만 채움)을 쓴다. 시작할 때 다시 심고, 끝나면 하니스가 고친 글을 되돌린다.
  ⚠️ **데모 DB 에 데이터를 쓴다.** DB 주소는 `DEMO_DATABASE_URL` > `DATABASE_URL` > `backend/.env` 순으로 읽고, 이름에 `prod` 가 들어 있으면 거절한다.
  (주소를 스크립트에 적어 두지 않는다 — 배포 전 점검이 접속정보 문자열을 막는다.)

이 하니스가 실제로 잡은 것(전부 눈으로는 "대충 괜찮아 보이던" 것):
- 모바일 저장 바가 두 줄로 꺾여 121px 이 되면서 **첫 화면의 [작품 사진 올리기] 를 덮었다** → 바를 한 줄로(안내 글자는 sm 이상에서만), 고친 것도 작품도 없으면 바를 그리지 않는다.
- 아이폰 SE(320px, WebKit)에서 [작품 정보 입력하기] 가 첫 화면 밖(y=492) → 그 줄을 [작품] 묶음 **맨 위**로, 완성도 칩을 한 줄 스크롤로.

⚠️ 눌림 판정은 `elementFromPoint` 다 — **그 요소를 화면 가운데로 올린 뒤** 재야 한다. 첫 화면 아래에 있는 칸을 그대로 재면 "가림"이 아니라 "화면 밖"이 실패로 찍힌다(하니스 자신의 오탐을 두 번 고쳤다).
