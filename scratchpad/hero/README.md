# 히어로 배너 잘림 하니스 (2026-10-01)

홈 배너(`frontend/src/components/home/HeroSlider.tsx`)가 **어느 엔진·어느 화면에서도 잘리지 않는지** 잰다.
크롬만 보면 못 잡는다 — 2026-10-01 의 잘림은 사파리(WebKit)에서만 났다.

```bash
bash scratchpad/hero/setup-webkit.sh        # 최초 1회 — WebKit 을 sudo 없이 띄울 준비(~/.cache/wk-deps)
# 로컬 프론트(5173)가 떠 있어야 한다. 백엔드·DB 는 건드리지 않는다(슬라이드·이미지를 가로채 넣는다).
cd e2e && PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 node ../scratchpad/hero/matrix.js
#   ENGINE=webkit|chromium  한쪽만 · SHOTS=1  스크린샷(out/) · BASE=https://artlink.cc  실서버를 같은 구성으로
```

- 2 엔진 × 8 화면(아이폰 SE·13·13 가로, 갤럭시 360, 픽셀 7, 아이패드 미니, PC 1280·1920) × 8 슬라이드 구성 = **128 조합**.
- 판정: 사진이 `contain` 으로 앉은 '그림 영역'이 트랙·슬라이드 칸 안에 **전부** 들어와 있는가(보임 100%),
  트랙이 세로로 스크롤되지 않는가, 페이지가 가로로 밀리지 않는가. 하나라도 어기면 종료 코드 1.
- 테스트 이미지는 네 변 색이 다른 SVG(위 빨강·아래 파랑·왼쪽 초록·오른쪽 자홍) — 스크린샷에서 어느 변이 잘렸는지 바로 보인다.

수정 전 실측(WebKit): PC 1280×720 에서 3:1 배너의 77.6% · 아이폰 13 가로 95.7% · 4:5 모바일 이미지 + 아이폰 13 세로 95.3% ·
16:9 배너는 46~57% 만 보였다. 크롬은 전부 100%. 원인과 고친 방법은 `HeroSlider.tsx` 의 주석과 CLAUDE.md 규칙 48.

## 글자 색(검정/흰색) 하니스 (2026-10-05)

사진 위 글자(자세히 보기·제목·넘김 표시·화살표)와 얇은 배너의 아래 줄이 **그 자리 배경에 맞는 색**인지 잰다.
판정은 화면이 쓰는 코드(`lib/heroTone.ts`)가 아니라 **스크린샷 픽셀**로 다시 한다 — 글자를 숨기고 같은 자리를 찍어 그 배경과의 명암비를 본다.

```bash
python3 scratchpad/hero/make-tone-images.py     # 최초 1회 — 테스트 배너(img/, 커밋 안 함). 실서버 이벤트 배너는 공개 주소에서 받는다
cd e2e && PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 node ../scratchpad/hero/tone.js     # TAG=이름 ENGINE= SCREEN= ONLY=A
python3 scratchpad/hero/tone_check.py [TAG]      # ✗ = 반대 색이 1.15배 넘게(그리고 3:1 이상) 더 잘 읽히는 자리
```

- 2 엔진 × 7 화면(PC 1920·1440·1366·1280·1024, 아이패드 미니, 아이폰 13) × 8 구성(실서버 배너 · 어두운 배너 · 구석만 어둡/밝은 배너 ·
  16:9 두 장 · 관리자 흰색 고정 · 썸네일 없는 옛 업로드 · 모바일 4:5) = 슬라이드 63장. 슬라이드·이미지를 가로채고 비회원 기록을 막는다(DB 무관).
- 고치기 전(2026-10-05, 크롬): 잘못 고른 자리 **77곳** — 실서버 배너의 [자세히 보기]가 1.1:1, 휴대폰 아래 줄 3.4:1.
  고친 뒤: 크롬·사파리 **0곳**, 실서버 배너 [자세히 보기] 15~18:1(검은 글자), 아래 줄 5.9:1.
- ⚠️ Tailwind v4 는 색을 `oklch()` 로 낸다 — 하니스도 화면도 1px 캔버스로 rgb 로 바꿔 읽는다(그냥 파싱하면 못 읽는다).
- ⚠️ 사파리는 전환(transition) 중에 찍히면 숨긴 넘김 표시가 남는다 — 숨기는 CSS 에 `transition:none` 이 있어야 한다.
